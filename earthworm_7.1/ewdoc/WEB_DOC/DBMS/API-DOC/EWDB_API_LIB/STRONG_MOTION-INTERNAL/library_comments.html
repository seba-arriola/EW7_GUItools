STRONG_MOTION-INTERNAL

Group: EWDB_API_LIB
Description: The STRONG_MOTION_INTERNAL library contains the code (both C & SQL) that supports the Strong Motion portion of the EWDB_API_LIB. This code is built to work with the second coming of the EW Strong Motion schema (v2.12 and later), and with rw_strongmotionII routines.
