archive

Group: EWDB_APPLICATIONS
Description: archive saves the contents of one or more DB Events to SAC directory(s). archive then deletes the data for each Event from the DB.

Events are selected by specifying a range of DB idEvents as a set of command line parameters to the program.

By using command line parameters, the user can also tweak the actions of archive, so that it does not save data to a SAC directory, or so it does not delete any or part of the Event data from the DB.
