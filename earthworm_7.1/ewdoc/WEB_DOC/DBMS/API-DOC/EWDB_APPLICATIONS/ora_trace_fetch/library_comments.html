ora_trace_fetch

Group: EWDB_APPLICATIONS
Description: ora_trace_fetch is the rear portion of the concierge system.

ora_trace_fetch processes snippet_requests that it retrieves from a table in the database, by repeatedly attempting to retrieve data from wave_servers. It has the ability to continually retrieve new data for a snippet as it becomes avaialable, thus allowing a snippet to grow incrementally over time.
