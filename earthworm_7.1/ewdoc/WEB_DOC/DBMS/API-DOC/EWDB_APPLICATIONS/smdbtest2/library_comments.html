smdbtest2

Group: EWDB_APPLICATIONS
Description: smdbtest2 is a simple stand-alone application that performs a minimal test of the strong motion functionality of an EW DBMS system. It utilizes the RW_STRONGMOTION_II and EWDB_API_LIB/STRONG_MOTION_API libraries.

Application Usage: smdbtest2 [DBUser] [DBPasswd] [DBSID]"
Where DBUser is the Oracle user to use for the test, DBPasswd is DBUser's password, and DBSID is the Oracle Service ID(SID) of the database you wish to use.

Initial version unclaimed!
