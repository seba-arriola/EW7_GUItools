ora2snippet_gif

Group: EWDB_APPLICATIONS
Description: ora2snippet_gif generates a web-page displaying snippets from an Event as record sections in GIF format.
There are config file parameters that control which traces are displayed, how the traces are aligned, how long the display is, and many other properties that will probably never change from the defaults. Please see the details page and the sample config file for more detailed information.
