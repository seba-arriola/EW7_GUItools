getlist

Group: EWDB_APPLICATIONS
Description: "getlist" is a cgi-bin program that generates customized maps of earthquakes. A list of events(earthquakes) is retrieved from an EWDB, and then a web page that lists all of the retrieved events(in both text-list and graphical-map form), along with summary information for each event, is created. It contains links to other programs that provide detailed information for a chosen event. In certain modes getlist will also display stations on the same map as the events.
