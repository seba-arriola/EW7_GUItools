arc2trigII

Group: EWDB_APPLICATIONS
Description: arc2trigII is an enhanced version of arc2trig.

arc2trig creates an Earthworm "trigger message" detailing snippets of waveform data from various channels that should be saved. The list of snippets is generated based upon the contents of a Hypoinverse Archive(arc) message.

arc2trigII further enhances the functionality of arc2trig by saving snippets of interest which were not listed in the arc message.
