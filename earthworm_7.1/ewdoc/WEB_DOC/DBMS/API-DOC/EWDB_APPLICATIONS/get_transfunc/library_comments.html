get_transfunc

Group: EWDB_APPLICATIONS
Description: get_transfunc is a simple test program that can be used to retrieve the Poles and Zeroes based cooked transfer function for a channel (at a given time) from an EWDB. It takes the id of the channel, connection parameters, and optionally time, as command line parameters, and dumps the function to standard out.
