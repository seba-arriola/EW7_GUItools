eqparam2html

Group: EWDB_APPLICATIONS
Description: eqparam2html generates a web-page with parametric information about an Event as well as a map depicting the location of the event and surrounding stations. It also provides links to other programs that allow the user to view record sections(waveform snippets), and station information.
