ora_trace_req

Group: EWDB_APPLICATIONS
Description: ora_trace_req is the front portion of the concierge system.

ora_trace_req reads a "trigger message" from an earthworm ring, parses the trigger_message, and creates snippet requests based on each channel-line in the trigger message. It then inserts each snippet request into the EW DBMS.
