EWDB_APPS_LIB

Description: This is a set of functions that serves the newer set of apps (DB, Interactive Review, Alarms, etc.) It includes two subsets: DB_LIB and SUPPORT_LIB. DB_LIB includes functionality to access the DB, and SUPPORT_LIB includes functionality for accessing map servers, and dealing with web protocols, and anything else that was designed to support the new line of apps.
