Scientific Constants

GRAVITY_CGS

Value: 978.03
Description: Gravity(g) in cm/sec/sec


Strong Motion Alternate Time Codes

SM_ALTCODE_AUTOMATED_REVIEWER

Value: 3
Description: Code for an alternate time derived by a Human (who has hopefully reviewed the data).


SM_ALTCODE_DATABASE

Value: 2
Description: Code for an alternate time derived by the database or strong motion database insertion module.


SM_ALTCODE_NONE

Value: 0
Description: Code for no alternate time.


SM_ALTCODE_RECEIVING_MODULE

Value: 1
Description: Code for an alternate time derived by a program module that receives a message from a box in the field.


Strong Motion Message Constants

SM_MAX_RSA

Value: 20
Description: Maximum number of spectral values for a given message.


SM_NULL

Value: -1
Description: NULL value for PGA, PGV, and PGD measurments. If any of the peak measurments for a message are not available, use SM_NULL in there place to indicate so. All measurements in the Earthworm TYPE_STRONGMOTION2 message are assumed to be positive. SM_NULL indicates that a measurement is missing, and any other negative value will result in unpredictable behavior from strong motion applications.
