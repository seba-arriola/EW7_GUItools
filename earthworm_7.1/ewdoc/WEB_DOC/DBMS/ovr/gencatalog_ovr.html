GENCATALOG: Details

Catalog Utility:
Gencatalog is a simple command-line program used to query the database to obtain a formatted list of events.

Command Format:
A variety of required and optional command line parameters (most search criteria) are passed on the command line. Execute the command without any parameters to obtain a description of the available options.
