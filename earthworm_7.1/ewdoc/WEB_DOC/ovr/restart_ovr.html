Earthworm Program:
Restart Overview

(last revised August 5, 1999)

The restart program sends an Earthworm TYPE_RESTART message with the specified pid to startstop, for manual restarting of individual modules. The pid can be obtained from the status message printed by status.

Warning: Under NT, wave_serverV cannot be safely restarted with the restart command. See wave_serverV overview instructions for correct method of stopping and restarting wave_serverV.
